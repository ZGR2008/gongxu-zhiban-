程序默认只展示待评测范围：

```powershell

# 使用上条输出的prepared-inputs.json路径
pnpm eval:prepare --historical-prompts=.runtime/historical-prompts-<id>/prepared-inputs.json
```

`--approved-live`只能在用户明确批准上述范围后另行使用，不属于`pnpm verify`。不接受任意目录或任意案例；每次实际调用保存参数、输入哈希、输出及哈希、状态、耗时、用量（可取得时）、失败和不完整输出。即使HTTP成功也不会自动写成语义质量通过。鉴权/限流/传输错误立即停止，无自动换提供方。

需求遗漏率按案例验收条目人工逐项判定，分别记录满足、遗漏、不可判断与对应输出片段；引用支持度逐项对照原文，不以引用ID存在作为支持。人工修改量及用时仅由实际审核者登记，没有审核就保留null。固定检索片段的提示词比较不能冒充端到端检索提升。当前不提供提升百分比或模型优劣结论。
