# 实际贡献、AI 使用与复核记录模板 v10

本文是待填写模板，不是已完成贡献证明。它与 `TEAM-WALKTHROUGH-V10.md` 的责任安排分开；尚未有任何成员的实际行为在此被认定为完成。脱敏版本仅写成员一／二／三，姓名与职责对应已由团队确认，仅在本地正式材料中保留实名，不公开学号、证件、账号或联系方式。

## 记录方式

- 一条记录对应一个真实发生的行为或问题。记录实际日期，不回填虚构日期，不修改 Git 历史制造参与证据。
- 如成果由 AI 生成，直接说明；使用现成代码、依赖或历史实现时写清来源，不把阅读／运行写成独立开发。
- “人工修改”“人工测试”“人工审核”分别记录。只阅读代码不能填测试通过，只运行测试不能填独立设计，只承担职责不能填已经完成。
- 引用证据文件、提交或输出位置；没有证据标“无／待补”，不编造哈希、截图、教师意见、用户反馈或准确率。
- 环境与模型标签使用：源码分析、离线单元／脚本、协议替身、真实数据库、实际浏览器操作、保存的真实模型响应审核、获授权现场真实模型调用。不能混为一种验证。
- 如涉及个人资料或原始会话，证据仅在本地受控保存；脱敏源码包只收录必要的摘要和空白模板，不能附密码、令牌、密钥、私人作业或他人账号信息。
- 本次模板不批准收费、上传、提权、公开访问或官网提交。此前真实模型调用授权不能自动续用。

填写规则：

1. 未执行就保留“未执行”；运行失败保留失败与定位，不删除失败记录后只留成功。
2. API 预置账号、网页点击、数据库检查分别说明；不能把 API 准备称为全程界面操作。
3. 重用已安装依赖写“复用本机环境”；只有实际空目录安装、实际空库迁移才记录相应事实，不能称为新机器验证。
4. 历史报告只作参考，必须注明报告日期／版本和本人没有执行的范围；不得将历史通过数量写为本人本次测试。
5. 演示的人工登记测试结果不等于自动执行业务代码；人工阶段验收不等于所有测试通过。
