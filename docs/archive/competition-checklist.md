## 作品要求

- [ ] 原创 Web 应用，AI 为核心，解决真实场景问题。
- [ ] 确认团队具有代码、知识资料和其他素材的使用权，记录第三方依赖及许可。
- [ ] 体现现代前端工程和真实可交互的 AI Native 体验。
- [ ] Agent 的实际工具调用、执行结果和失败状态可追踪。
- [ ] RAG 实际解析、向量化、检索知识并展示可核对的引用。
- [ ] 人工审核关键产物；未经验证的 AI 推测与真实检测结果分开。
- [ ] 向组委会确认多模态是否为逐件作品强制要求；截图中 MCP、端云协同属于背景介绍，未见对每件作品的强制条款。

## 省赛提交材料

- [ ] GitHub/Gitee 仓库公开，或提供评审访问权限；提交前检查敏感信息。
- [ ] 保留真实完整的 Git 提交历史，代码结构清晰，含必要注释。
- [ ] README 包含项目介绍、技术架构、安装运行指南、团队信息；附环境变量模板和依赖清单。
- [ ] 演示视频：5—8 分钟，MP4，至少 1080p，普通话讲解；覆盖项目、核心功能和 AI 技术亮点。
- [ ] 技术文档：PDF、不超过 30 页，包含项目概述、需求分析、系统架构、AI 技术方案、核心功能、测试部署、总结展望；说明 AI 选型、集成、优化及技术与应用创新。
- [ ] 在线演示为截图中的可选加分项；如提供，须公网可访问，评审期间保持可用，登录场景提供评审测试账号。
- [ ] 所有材料按赛事官网要求提交，提前验证访问权限并保存回执。
