# 工序智伴七分钟演示操作提纲

只使用原创校园借用合成案例。队员一讲解，队员二操作，队员三计时与核对；真实姓名及未来分工另在本地团队材料。下表是一页操作内容，逐字稿另见DEMO-SCRIPT-V7。

|时间|页面与操作|观众应看到|真实性与备用|
|---|---|---|---|
|0:00—0:35|工作区→借用需求|七日期限、禁止自批、原文版本|慢时用实际截图，说明是记录|
|0:35—1:20|教师`/teaching`→编辑七日首版→保存→确认并发布|同一草稿修订、首版已发布、班级进度|冲突保留输入，发布成功后才可领取|
|1:20—2:20|学生`/classroom`→领取项目→项目内需求与Agent入口|七日原文、候选、审核入口|已存候选/协议替身必须标明；不额外收费|
|2:20—3:35|教师发布三日新版→学生比较采纳→手动确认三日需求→文档/测试|旧依据历史提示、当前与历史版本分开|采纳不自动改学生正文；失败不跳到“完成”|
|3:35—4:40|提交→教师反馈退回→补自批步骤→重交→检查与例外验收|两份快照、已发布反馈、仍未执行/阻塞|不把阶段验收说成所有测试通过|
|4:40—5:30|知识库公共目录→阅读案例原文|51篇、已索引、版本及引用范围|只读或本地检索；不可用时明确只展示原文|
|5:30—6:25|离线真实响应审核HTML与PDF第16页|历史12次、新13次、长第9段失败、空白审核表|这是保存响应回放，无现场请求；人工评审未完成|
|6:25—7:00|追踪缺口→验证/分工|下一步、人机责任、已验证范围|不能给虚构完成率或教学提升比例|

开场前：用授权合成账号分别登录教师/学生两个独立浏览器会话；备好合成文本，按步骤预填或粘贴，仍逐次核对保存、发布和提交结果；确认本机服务就绪，核对已有候选，打开审核HTML和PDF，隐藏邀请码与个人信息。主库没有材料时先人工准备，不把隔离库当主库，不临时提权或复制私人作业。项目内路径统一为`/projects/<id>/requirements`、`/projects/<id>/agent`、`/projects/<id>/documents`、`/projects/<id>/tests`，使用实际项目ID或点击入口。

核心数据：借期七日→三日；申请人不得审批自己。提交保留“借用程序未实现，未执行学生代码”。教师例外理由限定“只接受需求与测试设计阶段，执行证据后补”。

中断处理：保存失败留在原页；未知模型结果不自动重试；切到同一案例的已保存真实截图时明确回放。禁止把协议替身称为真实模型、把回放称为现场生成、把教师验收称为测试全通过。

成片由参赛者制作：5—8分钟、普通话、MP4、至少1080p。七分钟是排练目标，未验证从零操作耗时；来不及时明确切到同一案例保存记录，不省略审核。成片需完整观看核对；本文不是已完成的视频，也不授权新收费调用。
