# v6 公共教学知识资料

用户明确授权本轮新建、检查后的非敏感原创教学资料进入平台公共知识库：所有现有和未来账号登录后共读；匿名禁止；普通学生/教师不可修改。**没有把任何原个人上传、作业或班级资料公开，也没有按账号复制。**

原知识库没有默认教学集合，个人目录只返回本人上传，公共集合本轮首次建立。不能从某个空目录推断用户没有其他账号资料；本轮不猜测当前账号、不读取私人正文。经迁移后个人目录仍维持原所有权过滤，搜索增加显式公共范围。

## 资料清单与来源

51篇：需求分析、项目规划、前端、后端与接口、数据库、测试验收、安全权限、项目交付各6篇，加校园物品借用、图书借阅、实训任务管理3个连贯案例。不是50份重复模板或占位数据，每篇包含场景、知识点、具体示例、常见错误、验收要点、分类、版本、来源及适用边界。

可重建源文件：`knowledge/teaching-v6/catalog.mjs`及各主题模块。可读文档：`output/teaching-v6/`（51篇Markdown及目录）。实际导入列表和内容哈希：`docs/verification/knowledge-v6.json`。当前版本1.0.0；不重复覆盖已有版本。

技术事实对照 PostgreSQL16、Fastify5.2.x、React19文档族、TypeScript5.x核心概念、Node24、MDN、W3C WCAG2.2和OWASP对应页面。准确链接/版本/访问日期保存在 `sources.mjs` 及每篇末尾。持续更新的官方文档不冒称不可变快照；Node站点24.22.2与本机24.22.1区别已注明。

业务规则均为项目原创合成教学设定，例如借用七日变三日，不是学校制度或官方标准。资料经AI辅助写作、工程和官方来源核对，**独立教师尚未审阅**；不能标为教材审定通过。未复制整本教材、其他作品代码、文案或素材；只链接官方技术依据。

## 实际索引与验收边界

本机批准批次已索引51篇、53块，使用本地向量服务；无新增聊天模型调用、无外部传输。26个问题保留原文召回，25个指定目标来源的问题均找到至少一个预期来源，另1个无答案问题不指定来源。**这只证明本批来源召回，不是准确回答率、拒答正确率或教学提升率。**

问题集 `evaluation/teaching-questions-v6.mjs` 包含明确有答案、无答案、七日/十四日冲突、恶意资料指令和权限隔离判定要点。无答案/冲突/恶意资料的正确回答需单独核对，未进行新的真实聊天调用。隔离数据库中另测：新老多个账号可读同份资料、匿名401、普通账号写入403、私人文档不进入他人检索、撤销维护角色后索引提交被拒绝。

来源名显式标注“平台公共教学示例”，可展开实际存储片段。引用存在不等于支持结论。未配置向量服务时资料仍可阅读，UI明确待索引，不能假报可检索。

## 导入与恢复

先构建API。`node scripts/import-teaching-curriculum.mjs --isolated`在独立库检查固定课程集合；主库经本轮明确授权可用`--apply-approved-public-curriculum`。只接受已纳入源码的固定课程，不接收任意文件路径，不调用远程Embedding。文件与哈希已检查；未知资料不自动公开。

每篇独立保存/索引、顺序推理；按哈希和当前模型标识跳过已完成项，失败记录在public_knowledge_imports。取消保留已保存文字；重新运行恢复失败或未完成项。第二次本机运行51篇均already_indexed，未增加记录。测试用合成替身检验推理中撤权与恢复；不把替身向量当真实多人负载。

若服务不可用，保留资料和明确失败状态，恢复本地向量服务后重跑。现有索引不得清空以掩盖问题。未来公共修订追加新版本；班级资料分享是另一种范围，本轮未默认开启。
