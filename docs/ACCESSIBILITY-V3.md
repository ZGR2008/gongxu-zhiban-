# 桌面可访问性检查记录（v3）

这份记录只说明本轮实际检查的范围，不是完整 WCAG 符合性声明，也不是比赛评分。依据截图中的用户体验、前端工程能力要求，以及用户明确提出的键盘、焦点和减少动态效果要求开展。

## 工具与数据边界

- 使用 Deque 官方 axe-core 4.14.0，MPL-2.0，仅为开发测试依赖，不进入应用生产包。
- 命令：`pnpm verify:accessibility`。可加 `--engine=webkit`（需本机对应 Playwright 浏览器）；普通可靠性测试与扫描分开计数。
- 在 1440×950 桌面、减少动态效果开启的独立浏览器上下文中运行；全部 API 响应为合成夹具，外部请求被拦截。无真实业务内容、凭据或页面上传。
- 检测 axe 支持的 WCAG 2.0/2.1 A、AA 标签规则；不等同覆盖这些标准全部条款。保留工具的 `incomplete` 项，不将其计为通过。

## 问题与修复证据

首轮报告 `.runtime/reliability-ui-0fc846d4-142e-4462-887e-134c123f4a26/report.json` 在13个工作页面复现快速导航名称不包含完整可见文字，代码审查另有两个字号按钮同类问题。随后快速导航弹窗也复现 Esc 关闭按钮名称不一致。两个统计区域被提示 aria-label 缺少有效角色，人工核对后补上分组语义。

现统一可见文字与可访问名称，提供实际快捷键属性；两处统计使用 `role="group"`，不改变显示数据或业务行为。登录首轮夹具错误设置了登录状态而未进入登录页，修正为独立未登录上下文后重新检查，保留失败报告。

检查还发现重复侧栏没有跳过入口，选中导航仅有样式。新增键盘回归在修改前失败；修复后首次 Tab 可聚焦“跳到主要内容”，Enter 将焦点放到具有页面名称的主内容区域，URL 与浏览器历史长度不变，下一次 Tab 在主区域内继续。导航选中项增加 `aria-current="page"`。链接仅在聚焦时出现，沿用现有动效和减少动态效果策略，不新增装饰层。

## 已执行范围与结果

R19完成后的报告 `.runtime/reliability-ui-805b484e-0a00-4186-9df8-9230bfc82431/report.json` 的19个扫描均未发现工具判定的违规：工作台、项目列表、实训库、运行记录、交付检查、知识库、成长、项目概览、需求、Agent、代码审查、测试、文档、编辑离开保护、登录、快速导航、显示设置、新建项目、需求历史。**这只代表所选合成状态中的自动扫描结果。** 原报告 `22267ffc-438f-4d39-931a-80192f61ac03` 留存为改进前后阶段记录，不用旧结果代替当前复核。

每个页面仍有渐变/毛玻璃背景的对比度不确定项；新建和历史面板的“×”关闭符号也由工具要求人工判定。该符号是配有明确关闭名称的图标，不将符号改成无意义读音以消除工具提示。已查看工作台与快速导航实际截图；没有据截图目测宣称所有文字达到对比度标准。

真实本地 UI 检查 `.runtime/ui-6fd1d145-fad0-4404-b029-ea7b6c0556ae/report.json` 的8组通过，包括快捷导航焦点、显示偏好、代码字号与复制、真实知识资料索引和既有布局。它使用新建合成账号及真实本地服务，不调用收费模型。新增跳过导航回归与全工作区类型检查通过。

## 尚未完成的人工验收

U4补查复现了强制颜色下的选中状态缺失：显示设置的两组自定义单选框只剩相同边框，侧栏当前项的背景也失去区别。新增`forced-colors`规则只给当前/按下/单选选中项增加下划线，并为快速导航的键盘选项增加系统色轮廓；未设置`forced-color-adjust:none`来绕过用户配色，也未改变正常深色主题。

两条受控回归在修复前确实失败，修复后Edge通过，实际前后截图已查看。首次脚本缺少URL工具导入产生ReferenceError，修正后才取得真正的AssertionError与界面证据；没有把脚本错误当产品问题。Edge中的渐变标题和主按钮原本可见，未为这些已有正常行为重写样式。

Windows WebKit27.2模拟可触发媒体查询，但本机截图仍使用原调色板和渐变；首次把其当完整强制调色渲染导致颜色断言失败。保留该报告，将完整调色检查明确列为此引擎未执行，另一个仅检查媒体规则、选中样式与键盘关闭的用例继续运行，不宣称WebKit高对比度验收通过。工具定义只承诺[媒体特征模拟](https://playwright.dev/docs/api/class-page#page-emulate-media)，[MDN强制颜色说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/forced-colors)用于核对受影响属性与小范围修正原则；实际系统模式仍未测试。
