## 5. 复核方式与限制

在装有已锁定依赖的项目根目录运行：

```powershell
python scripts/audit-licenses-v8.py --pdf output/pdf/gongxu-zhiban-technical-v7-20261102-113909-250524.pdf
```

PDF 检查使用材料环境的 `pypdf`。没有该可选依赖时可不传 `--pdf`，不能因此声称已检查 PDF 字体。文件记录版本、哈希、静态资源清单、字体标记和未完成项；不输出版权方以外的团队个人数据或秘密。

该检查不能鉴定生成内容侵权、确定每一行的作者、确认所有传递依赖再分发义务或代替比赛官方认定。现阶段结论为：**主要直接依赖和已打包组件的来源／许可已核对；官网允许 AI 辅助工具但要求代码解释能力，本队对应届次、实际能力及特定披露要求待核；团队实际贡献与独立审核仍缺少证据。**
