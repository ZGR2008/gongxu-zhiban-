# 外部源码评审包说明

本轮目标文件名 `gongxu-zhiban-review-v3.zip`；桌面已有同名文件时加时间戳，保留v2及其他旧包。源码包不含Git目录，不能替代截图要求的完整真实Git比赛仓库。

保留前后端/向量服务源码、配置模板、依赖与锁文件、迁移、单元与浏览器测试、评测脚本、README、启动与恢复说明、最终报告、第三方许可，以及本轮明确标注为合成数据的桌面截图。

排除node_modules、.venv、构建产物、缓存、日志、.git、真实.env、凭据文件、模型权重、上传资料、数据库及业务数据。历史截图、历史运行报告和敏感性无法确认的文件先排除，并在包内 `SOURCE-PACKAGE-MANIFEST.json` 按路径说明原因。不会读取真实.env来比对密钥。

`scripts/export-review.py`按白名单遍历源码，扫描提供方令牌、私钥块、带/不带引号的凭据字段和带凭据数据库URL；只在副本中替换占位符。短输入替换保持长度，避免破坏长度边界测试；完整界面文案与字符串拼接不当作凭据字段。Compose和数据库模板在副本中使用独立评审配置；原项目和本地环境不改。测试PDF只保留已核对的合成正文并移除元数据，PNG移除可携带隐私的文本/EXIF块。每个入包文件有大小与SHA-256清单；只记录命中规则和文件名，不输出秘密。

JSON只纳入明确的包/编译配置、模型许可清单、版本化评测案例/模板及本轮审核材料。未知JSON、数据文本、非迁移SQL、未核对的配置与截图先排除；目录链接解析到源码根之外时不跟随。规则性扫描不能证明任意格式的未知秘密全部不存在，正式对外分享前仍应人工复核清单。

重新导出需要Python 3，以及仅供打包工具使用的`pypdf`；固定版本见`scripts/requirements-review.txt`。在独立工具环境安装该清单后运行`python scripts/export-review.py`，结果位于项目父目录的`.review-export/`下，不自动向桌面或外部平台写入。主应用仍只需原Node依赖；本轮使用此前已有的本机PDF工具，没有为了打包新下载软件。

扫描不能数学证明不存在未知格式的秘密；不确定的材料已排除。ZIP完整性、解压后模板检查、PDF夹具以及源码副本检查的实际结果在最终报告。最终包仅保存本地桌面，不自动上传；正式对外发送仍需用户自行授权。

打包工具回归：`python scripts/export-review.test.py`，仅创建临时合成文件，检查敏感文件在读取前排除、原文件哈希不变、引号/短值脱敏、越界目录与旧包保护，以及脱敏后的工具源码可解析。副本测试复用本机已有依赖，不代表全新机器的联网安装验收；包管理器拒绝依赖目录链接时不关闭该保护，可用既有编译器直接核对副本，命令须从各工作区目录执行以正确读取Tailwind配置。
